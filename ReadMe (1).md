# 💫 About Me:
I'm a Python developer focused on building Retrieval-Augmented Generation (RAG) systems — connecting large language models to real data using vector embeddings and similarity search. I work with ChromaDB to build in-memory vector search engines, and use Git and VS Code as part of my daily workflow.<br> <br>Before moving into AI/ML development, I built a background in graphic design and UI, which shapes how I think about the software I build — not just whether it works, but whether it's usable and well-structured. That combination lets me work across the stack: from designing an interface to building the retrieval logic behind it.<br> <br>I'm currently deepening my skills in AI engineering and LLM workflows, and looking to apply that in real-world projects and roles. Open to connecting with others working in AI, RAG, and Python development.
